# Projet de synthèse – Risque de crédit

## Description
Ce projet de synthèse vise à analyser et prédire le risque de défaut de paiement des clients
à l’aide de techniques de science des données, d’analyse statistique, de visualisation des données,
de séries temporelles (ARIMA) et d’apprentissage automatique.

## Données
- Données clients : UCI Machine Learning Repository (Default of Credit Card Clients)
- Données macroéconomiques : World Bank (taux de chômage)

## Objectifs
- Analyse statistique des profils clients
- Visualisation des comportements de défaut
- Analyse de séries temporelles (ARIMA) du taux de chômage
- Modélisation du risque de défaut par apprentissage automatique
## Méthodologie 
1. Chargement et nettoyage des données
2. Analyse statistique exploratoire
3. Visualisation des variables clés
4. Analyse de séries temporelles (ARIMA)
5. Construction des variables explicatives
6. Modélisation du risque par apprentissage automatique
7. Évaluation des modèles (accuracy, precision, recall, F1-score)
8. Interprétation des résultats et discussion

## Technologies

- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
